# MEMARASIX — agent/

Independent statistics collection module (planned).

Scope: football leagues and NBA configured in the ESPN fixture collector. Inputs will be read-only fixture identifiers from collector outputs; statistics are stored separately. No publication, selection, bankroll, archive, or main-site writes.

Statistical sources, coverage audit, schemas, triggers, and retry behavior will be defined and tested before implementation. The agent must distinguish verified statistics from missing or unavailable data.
